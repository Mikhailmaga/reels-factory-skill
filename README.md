# Reels Factory 3.1.1 для Codex

Локальная агентная фабрика вертикальных роликов для Windows и macOS. Она сначала настраивается под человека и бренд, затем анализирует каждый исходник, согласует производственную карточку и только после этого монтирует Reel.

**Никогда не работали с Codex и монтажом?** Откройте [пошаговую инструкцию для начинающих](BEGINNER-GUIDE-RU.md): там есть готовые сообщения для копирования, примеры ответов и объяснение каждого этапа простыми словами.

## Что нового в 3.1.1

- принцип Codex-first: внешний платный сервис больше не является обычным этапом производства;
- исходник, локальный монтаж, титры, графика, SVG, эффекты и анимация используются раньше любой генеративной модели;
- встроенная генерация изображений Codex может подготовить обложку, фон или статичный B-roll без отдельного API-ключа, если она доступна в текущем тарифе и рабочем пространстве;
- созданные и импортированные медиаресурсы получают локальную карточку происхождения;
- fal.ai сохранён как заблокированный по умолчанию резерв для задач, где действительно нужно новое сгенерированное видео.
- установочная цепочка закрепляет версии и проверяет SHA-256 до запуска внешних файлов.

## Основа фабрики 3

- короткий онбординг с сохранением личного профиля;
- вопросы о цели, площадке, длительности, стиле, цветах и CTA **до** начала монтажа;
- локальный анализ видео: метаданные, звук, тишина, сцены и девять контрольных кадров;
- русский транскрипт, четыре стиля субтитров и три позиции;
- динамическое кадрирование, hook, CTA, B-roll, музыка и приглушение музыки под речь;
- proof из пяти кадров до дорогого финального рендера;
- готовый MP4, обложка PNG, субтитры JSON/SRT и QC-отчёт;
- локальная работа по умолчанию без публикации и без обязательных API-ключей.

Предыдущие версии сохранены отдельными тегами и релизами: [`v2.0.0`](https://github.com/Mikhailmaga/reels-factory-skill/releases/tag/v2.0.0), [`v3.0.0`](https://github.com/Mikhailmaga/reels-factory-skill/releases/tag/v3.0.0) и [`v3.1.0`](https://github.com/Mikhailmaga/reels-factory-skill/releases/tag/v3.1.0).

## Полная установка одной командой в Codex

Открой **локальный** Codex на компьютере, вставь сообщение целиком и отправь:

```text
Установи только Reels Factory 3.1.1 из закреплённого релиза.

Архив:
https://github.com/Mikhailmaga/reels-factory-skill/releases/download/v3.1.1/reels-factory-v3.1.1.zip

Ожидаемый SHA-256:
3A156A63673A0FC1DC856B1766537EC68E0509040B15612610BCF57AB8708CEA

Определи мою операционную систему. Скачай по HTTPS только этот архив во временную папку,
вычисли SHA-256 и сравни с ожидаемым значением до распаковки. При несовпадении остановись
и ничего не запускай. При совпадении распакуй архив, запусти install.ps1 на Windows или
install.sh на macOS и работай до появления INSTALLATION.json со статусом ready,
factoryVersion 3 и factoryRelease 3.1.1. Не запрашивай API-ключи, токены или пароли.
После установки проверь фабрику и начни её личную настройку.
```

Codex проверит архив, выберет `install.ps1` для Windows или `install.sh` для macOS и создаст локальную рабочую папку. Системный пароль, если он потребуется для установки зависимостей, вводится только в системном интерфейсе — не в чате.

## Что написать после установки

```text
$reels-factory проверь установку и настрой мою фабрику
```

После сохранения профиля достаточно написать:

```text
$reels-factory сделай новый Reels
```

Скилл задаст короткие вопросы **до загрузки ролика**, затем попросит видео, покажет производственную карточку и будет ждать согласования. Рендер запускается только после подтверждения.

Отдельная команда установки из изменяемой ветки `main` не публикуется: она обходила бы проверку релизного ZIP. Даже если часть зависимостей уже установлена, используй закреплённую команду выше.

## Локальный комплект

- Node.js 22 и npm;
- FFmpeg и FFprobe;
- Remotion 4 и совместимый браузерный движок;
- Whisper.cpp с русской моделью `base`;
- скилл `reels-factory` и диагностическая команда doctor.

Подробности: [`skill/reels-factory/INSTALL.md`](skill/reels-factory/INSTALL.md). Встроенная генерация изображений зависит от доступных возможностей Codex и расходует лимит Codex; отдельный API-ключ для неё не нужен. Внешняя AI-генерация через fal.ai опциональна, выключена по умолчанию и запускается только после доказанной необходимости и отдельного согласия на платный вызов.
