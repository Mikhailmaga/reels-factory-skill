# Reels Factory для Codex

Кроссплатформенный локальный скилл для производства вертикальных Reels: личный профиль, обязательное согласование карточки, монтаж, русская расшифровка, титры, proof-кадры, финальный MP4 и QC.

Поддерживаются Windows 10/11 и macOS на Apple Silicon или Intel. API-ключи не нужны. Видео не загружается в облако и автоматически не публикуется.

## Полная установка одной командой в Codex

Открой **локальный** Codex на компьютере, вставь сообщение целиком и отправь:

```text
Установи Reels Factory по официальной инструкции:
https://raw.githubusercontent.com/Mikhailmaga/reels-factory-skill/main/INSTALL-CODEX.md

Определи мою операционную систему, скачай только указанный релиз, проверь SHA-256,
запусти подходящий установщик и работай до появления INSTALLATION.json со статусом ready.
Не запрашивай и не используй API-ключи, токены или пароли.
```

Codex скачает проверенный релиз и выберет `install.ps1` для Windows или `install.sh` для macOS. Система может один раз запросить разрешение администратора или пароль Mac для установки локальных зависимостей. Пароль вводится только в системном интерфейсе, не в чате.

## Только установить скилл

Если Node.js, FFmpeg, Remotion и Whisper уже установлены, можно использовать системный установщик скиллов Codex:

```text
$skill-installer Установи скилл из https://github.com/Mikhailmaga/reels-factory-skill/tree/main/skill/reels-factory
```

На следующем ходу вызови:

```text
$reels-factory настрой мою личную фабрику Reels
```

## Что устанавливается локально

- Node.js 22 и npm.
- FFmpeg и FFprobe.
- Remotion и браузерный движок рендера.
- Whisper.cpp и русскоязычная модель `base`.
- Скилл `reels-factory`.

Подробности ручной установки находятся в [`skill/reels-factory/INSTALL.md`](skill/reels-factory/INSTALL.md). Условия использования Remotion регулируются его собственной лицензией.
