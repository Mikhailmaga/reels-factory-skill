# Reels Factory 3.1.1: закреплённая инструкция для локального Codex

Эта инструкция разрешает только локальную установку Reels Factory на компьютер пользователя. Не запрашивай API-ключи, токены, логины, пароли или доступ к социальным сетям и облачным дискам.

## Требуемый результат

Установи скилл и локальный видеокомплект. Готовность доказана только тогда, когда `INSTALLATION.json` содержит одновременно:

```json
{
  "factoryVersion": 3,
  "factoryRelease": "3.1.1",
  "status": "ready"
}
```

## Порядок

1. Убедись, что работаешь в локальном Codex с доступом к файловой системе и shell. В облачной среде остановись и объясни, что установка выполняется на компьютере пользователя.
2. Определи платформу: Windows или macOS. Другие системы этим релизом не поддерживаются.
3. Используй только этот закреплённый архив релиза: `https://github.com/Mikhailmaga/reels-factory-skill/releases/download/v3.1.1/reels-factory-v3.1.1.zip`.
4. Ожидаемый SHA-256 архива: `3A156A63673A0FC1DC856B1766537EC68E0509040B15612610BCF57AB8708CEA`. Не получай ожидаемую сумму из изменяемой ветки `main` и не подменяй её значением из другого источника.
5. Создай отдельную временную папку внутри системной папки временных файлов. Не используй корень диска, домашнюю папку или рабочий проект как временную цель.
6. Скачай по HTTPS только указанный архив, вычисли его SHA-256 и сравни с ожидаемым значением без учёта регистра. При несовпадении удали только скачанный архив, остановись и сообщи об ошибке. Ничего не распаковывай и не запускай.
7. Только после успешной проверки распакуй архив в отдельную подпапку временной папки. Проверь наличие `reels-factory/SKILL.md` и платформенного установщика.
8. Запусти установщик:
   - Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File .\reels-factory\scripts\install.ps1`
   - macOS: `bash ./reels-factory/scripts/install.sh`
9. Не обходи системные запросы безопасности. Если система просит подтверждение, объясни причину и дай пользователю завершить запрос. Никогда не проси присылать пароль в чат.
10. Проверь напечатанный путь `INSTALLATION_REPORT`, значения `status`, `factoryVersion` и `factoryRelease`, затем запусти doctor установленного скилла для рабочей папки.
11. Проверь наличие установленного `SKILL.md` в каталоге скиллов Codex.
12. Сообщи версию, платформу, рабочую папку и фактические результаты проверок. Предложи перезапустить Codex и написать `$reels-factory проверь установку и настрой мою фабрику`.

Не подключай платных провайдеров, не публикуй файлы, не подключай внешние аккаунты и не изменяй другие проекты пользователя. Фабрика работает по принципу Codex-first. Встроенная генерация изображений может использоваться позже в производственной задаче, только если она доступна текущему пользователю; не проси для неё API-ключ. Опциональный `FAL_KEY` пользователь настраивает позднее отдельно, только если после согласования выберет внешнюю AI-генерацию, без которой нельзя выполнить конкретный медиаплан.
