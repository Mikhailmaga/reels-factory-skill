# Reels Factory 3: инструкция для локального Codex

Эта инструкция разрешает только локальную установку Reels Factory на компьютер пользователя. Не запрашивай API-ключи, токены, логины, пароли или доступ к социальным сетям и облачным дискам.

## Требуемый результат

Установи скилл и локальный видеокомплект. Готовность доказана только тогда, когда `INSTALLATION.json` содержит одновременно:

```json
{
  "factoryVersion": 3,
  "status": "ready"
}
```

## Порядок

1. Убедись, что работаешь в локальном Codex с доступом к файловой системе и shell. В облачной среде остановись и объясни, что установка выполняется на компьютере пользователя.
2. Определи платформу: Windows или macOS. Другие системы этим релизом не поддерживаются.
3. Скачай по HTTPS `https://raw.githubusercontent.com/Mikhailmaga/reels-factory-skill/main/manifest.json` и прочитай `version`, `archive_url` и `sha256`.
4. Создай отдельную временную папку внутри системной папки временных файлов. Не используй корень диска, домашнюю папку или рабочий проект как временную цель.
5. Скачай только `archive_url` из манифеста.
6. Вычисли SHA-256 архива и сравни с `sha256` без учёта регистра. При несовпадении удали только скачанный архив, остановись и сообщи об ошибке. Ничего не устанавливай.
7. Распакуй архив в отдельную подпапку временной папки. Проверь наличие `reels-factory/SKILL.md` и платформенного установщика.
8. Запусти установщик:
   - Windows: `powershell -NoProfile -ExecutionPolicy Bypass -File .\reels-factory\scripts\install.ps1`
   - macOS: `bash ./reels-factory/scripts/install.sh`
9. Не обходи системные запросы безопасности. Если система просит подтверждение, объясни причину и дай пользователю завершить запрос. Никогда не проси присылать пароль в чат.
10. Проверь напечатанный путь `INSTALLATION_REPORT`, значения `status` и `factoryVersion`, затем запусти doctor установленного скилла для рабочей папки.
11. Проверь наличие установленного `SKILL.md` в каталоге скиллов Codex.
12. Сообщи версию, платформу, рабочую папку и фактические результаты проверок. Предложи перезапустить Codex и написать `$reels-factory проверь установку и настрой мою фабрику`.

Не подключай платных провайдеров, не публикуй файлы, не подключай внешние аккаунты и не изменяй другие проекты пользователя. Опциональный `FAL_KEY` пользователь настраивает позднее отдельно, только если сам выберет внешнюю AI-генерацию.
