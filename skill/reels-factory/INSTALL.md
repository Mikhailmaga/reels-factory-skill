# Установка Reels Factory 3

Один установщик ставит скилл и локальный видеокомплект: Node.js 22, FFmpeg/FFprobe, Remotion, браузер для рендера и Whisper.cpp с русской моделью `base`. Исходники и результаты остаются на компьютере; автоматической публикации нет.

## Windows 10/11

1. Распакуй ZIP в обычную папку.
2. Открой PowerShell в распакованной папке.
3. Выполни:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Установщик использует Windows Package Manager. Если его нет, Node.js скачивается с официального сайта Node.js, а FFmpeg — из Windows-сборки, на которую ссылается официальный сайт FFmpeg.

## macOS 15 или новее — Apple Silicon и Intel

1. Распакуй ZIP в обычную папку.
2. Открой Terminal в распакованной папке.
3. Выполни:

```bash
bash ./scripts/install.sh
```

Установщик определит архитектуру через Homebrew. На Apple Silicon Homebrew обычно использует `/opt/homebrew`, на Intel — `/usr/local`. Если Homebrew или Command Line Tools отсутствуют, macOS может запросить пароль и подтверждение в Terminal — это штатная системная защита.

## После установки

Дождись `INSTALLATION_REPORT`, проверь `"status": "ready"` и `"factoryVersion": 3`, перезапусти Codex и напиши:

```text
$reels-factory проверь установку и настрой мою фабрику
```

Рабочая папка по умолчанию:

- Windows: системная папка `Документы\ReelsFactory`;
- macOS: `~/Documents/ReelsFactory`.

Повторный запуск обновляет движок, сохраняет прежний скилл резервной копией и не удаляет `PROFILE.md`, исходники или готовые работы.

Первичная установка требует интернета и нескольких гигабайт свободного места. При оборванной загрузке запусти тот же установщик повторно: безопасно переиспользуемые компоненты будут использованы снова.

## Опциональная AI-генерация

Основной монтаж полностью локальный. Если пользователь отдельно решит использовать fal.ai для B-roll или других материалов, он самостоятельно задаёт локальную переменную окружения `FAL_KEY`. Скилл не запрашивает ключ в чате и не выполняет платную генерацию без явного подтверждения.
