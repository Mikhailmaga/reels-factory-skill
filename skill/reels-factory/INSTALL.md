# Установка «Фабрики Reels» 2.0

Один установщик ставит сам скилл и весь локальный видеокомплект: Node.js 22, FFmpeg/FFprobe, Remotion, браузер для рендера и Whisper с русской моделью `base`. Исходники и готовые ролики остаются на компьютере; автоматической публикации нет.

## Windows 10/11

1. Распакуй ZIP в обычную папку.
2. Открой PowerShell в распакованной папке.
3. Выполни:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Установщик сначала использует официальный Windows Package Manager. Если его нет, Node.js скачивается с официального сайта Node.js, а FFmpeg — из готовой Windows-сборки, на которую ссылается официальный сайт FFmpeg.

## macOS — Apple Silicon и Intel

1. Распакуй ZIP в обычную папку.
2. Открой Terminal в распакованной папке.
3. Выполни:

```bash
bash ./scripts/install.sh
```

Установщик определит архитектуру через Homebrew. На Apple Silicon Homebrew использует `/opt/homebrew`, на Intel — `/usr/local`. Если Homebrew или Command Line Tools отсутствуют, macOS может попросить пароль и подтверждение их установки — это штатная системная защита, обойти её безопасно нельзя.

## После установки

Дождись строки `Готово`, перезапусти Codex и напиши:

```text
Используй $reels-factory и настрой мою личную фабрику Reels.
```

Рабочая папка по умолчанию:

- Windows: системная папка `Документы\ReelsFactory`.
- macOS: `~/Documents/ReelsFactory`.

Повторный запуск установщика безопасно обновляет движок, сохраняет прежний скилл резервной копией и не удаляет `PROFILE.md`, исходники или готовые работы.

Первичная установка требует интернета и нескольких гигабайт свободного места. Если загрузка оборвалась, запусти тот же установщик повторно: уже скачанные компоненты переиспользуются.
