# Установка Reels Factory 3.1.1

Один установщик ставит скилл и локальный видеокомплект: Node.js 22, FFmpeg/FFprobe, Remotion, браузер для рендера и Whisper.cpp с русской моделью `base`. Исходники и результаты остаются на компьютере; автоматической публикации нет.

## Windows 10/11

1. Распакуй ZIP в обычную папку.
2. Открой PowerShell в распакованной папке.
3. Выполни:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Установщик использует закреплённые версии Node.js и FFmpeg. Windows Package Manager проверяет свои пакеты; резервные загрузки дополнительно сверяются с зафиксированными SHA-256 до установки или распаковки.

## macOS 15 или новее — Apple Silicon и Intel

1. Распакуй ZIP в обычную папку.
2. Открой Terminal в распакованной папке.
3. Выполни:

```bash
bash ./scripts/install.sh
```

Установщик определит архитектуру через Homebrew. На Apple Silicon Homebrew обычно использует `/opt/homebrew`, на Intel — `/usr/local`. Если Homebrew отсутствует, его официальный установщик сначала скачивается из закреплённого commit и проверяется по SHA-256. Если Homebrew или Command Line Tools отсутствуют, macOS может запросить пароль и подтверждение в Terminal — это штатная системная защита.

## После установки

Дождись `INSTALLATION_REPORT`, проверь `"status": "ready"`, `"factoryVersion": 3` и `"factoryRelease": "3.1.1"`, перезапусти Codex и напиши:

```text
$reels-factory проверь установку и настрой мою фабрику
```

Рабочая папка по умолчанию:

- Windows: системная папка `Документы\ReelsFactory`;
- macOS: `~/Documents/ReelsFactory`.

Повторный запуск обновляет движок, сохраняет прежний скилл резервной копией и не удаляет `PROFILE.md`, исходники или готовые работы.

Первичная установка требует интернета и нескольких гигабайт свободного места. При оборванной загрузке запусти тот же установщик повторно: безопасно переиспользуемые компоненты будут использованы снова.

## Codex-first и опциональная AI-генерация

Основной монтаж, титры, графика, эффекты и анимация выполняются локально. Если в текущем Codex доступна встроенная генерация изображений, скилл может использовать её для согласованной обложки или статичного B-roll без отдельного API-ключа. Доступность и лимиты зависят от тарифа и рабочего пространства Codex.

fal.ai не включается автоматически и не является следующим шагом при недоступности встроенной генерации. Он остаётся резервом для задачи, где действительно необходимо новое сгенерированное видео. В таком случае пользователь самостоятельно задаёт локальную переменную окружения `FAL_KEY`, а скилл заранее показывает модель, входные данные и ожидаемую стоимость и ждёт отдельного подтверждения.
